# Day 1 学习笔记 · 神经网络直觉 + 线性回归（Linear Regression）

## 今天最大的收获：一套能套用到所有模型的思维框架

拿到任何机器学习问题，我现在会用三步拆解：

1. **模型(model)**：用什么函数来预测 → 决定这个模型有哪些参数
2. **损失(loss)**：怎么量化"预测得有多差"（一个越小越好的数）
3. **优化(optimization)**：怎么调参数，让损失变小

这三步循环起来就是"训练"。线性回归只是这个框架里最简单的一个实例，后面的 CNN、具身智能里的策略网络，骨架其实一模一样。**这套框架比线性回归公式本身重要得多。**

---

## 核心知识点

### 1. 神经网络的直觉

一个**神经元(neuron)** = 加权求和（`Σ wᵢxᵢ + b`）+ 激活函数。神经网络就是一堆神经元分层连起来。
- `w`（权重）决定某个输入有多重要，`b`（偏置）是整体平移量。
- 神经网络本质是"一个带大量可调参数的函数"，**训练 = 不停拧 `w`、`b` 这些旋钮**，直到输出接近正确答案。

### 2. 线性回归 = 最简单的单层神经网络

- 模型：`ŷ = w·x + b`（多特征时是向量点积 `ŷ = w·x + b`）
- 它就是**一个神经元 + 恒等激活**（激活函数啥也不做，原样输出）。
- 参数是 `w`、`b`（要学的）；`x` 是输入（给定的）——**这俩绝不能搞混**。

### 3. 损失函数 MSE

```
L = (1/n) · Σ(ŷᵢ − yᵢ)²
```

为什么平方：① 消除正负号，避免误差正负相消；② 放大大误差，逼模型先改大错；③ 处处可导，方便后面的梯度下降。

## 代码实验里最关键的一张图

画"loss 随 w 变化"的曲线，得到一条**开口向上的抛物线**，有唯一最低点。

→ 顿悟：**找最优参数 = 找这条曲线的最低点**。怎么自动走到最低点？沿着下坡方向一步步走——这就是明天要学的**梯度下降**。

---

## 我要注意的坑（易混点）

- `rand`（均匀分布）vs `randn`（正态分布），就差一个 `n`，别记混。
- `X * w` 是**广播 / 向量化**，一行代码对所有样本同时运算，不用手写 `for` 循环。
- **参数 `(w, b)` 和 输入 `x` 一定分清**：训练中会变的只有 `w`、`b`。

## 重点思考题（复习时先自己答，别看下面的要点）

**Q1. 为什么 MSE 要对误差平方，而不是直接相加？**
> 要点：①消除正负号避免抵消；②放大大误差逼模型先改大错；③处处可导，方便梯度下降。

**Q2. 为什么说线性回归是"最简单的单层神经网络"？**
> 要点：一个神经元（加权求和+偏置）+ 恒等激活（啥也不做）+ 只有一层。

**Q3. "loss 随 w 的抛物线"给自动找最优参数什么启发？**
> 要点：碗状曲线有唯一最低点 → 像下山一样沿"下坡方向"一步步走到谷底 → 这就是梯度下降。

**Q4.（思维流程迁移）用「模型→损失→优化」拆解一个新问题：**
> 用"学习时长 x₁、睡眠时长 x₂"预测总评。
> ①模型 ŷ=w₁x₁+w₂x₂+b（3 个参数）；②损失 MSE；③目标：调 w₁,w₂,b 让 MSE 最小。
