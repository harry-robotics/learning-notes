# Day 4 学习笔记 · 多层感知机（MLP）+ 激活函数

## 今天把网络加深加非线性，得到真正的神经网络

前三天单层线性只能拟合直线；今天加**隐藏层 + 非线性激活**，网络才能表达弯曲、复杂的函数。「模型—损失—优化」框架不变——只是"模型"从线性回归升级成了 MLP，损失还是 MSE，优化仍靠梯度下降 + 反向传播。

---

## 核心知识点

### 1. 为什么必须加非线性激活（今天的灵魂）

只堆线性层会**塌缩**：`W2(W1x+b1)+b2 = W'x+b'`，叠多少层都等价于单层线性，白叠。
→ 在每个线性层后插一个**非线性激活**，打破塌缩，网络才有"深度"的意义。

### 2. MLP 前向三步

```
z1 = X·W1 + b1     （线性）
a1 = 激活(z1)       （非线性）
z2 = a1·W2 + b2    （线性，输出 ŷ）
```
形状要对上：`(n,d)·(d,h)=(n,h)`，**中间维必须相等并抵消**。

### 3. 激活函数对比

- **sigmoid** `1/(1+e⁻ᶻ)`：压到 (0,1)，导数最大才 **0.25** → 深层连乘 → **梯度消失**，隐藏层现在少用。
- **ReLU** `max(0,z)`：导数 z>0 为 **1**、z<0 为 0。正区间**不衰减梯度 → 缓解梯度消失**（收掉 Day 3 的伏笔），计算快，**现代隐藏层默认**。小缺点：dead ReLU。

### 4. `@` vs `*`

`@` 矩阵乘法，`*` 逐元素乘，**别混**。层间用 `@`，激活函数内部是逐元素。

## 易错点（常见高频坑）

> 这次没自己做题，以下是这块内容的通用高频坑，先记着，等以后自己动手做题时把真正踩到的补进来。

- **`@` 和 `*` 混用**：MLP 层间是矩阵乘 `@`；激活、加偏置这些是逐元素。用错直接形状报错或算错。
- **矩阵形状对不上**：牢记 `(n,d)·(d,h)=(n,h)`，中间维不等就没法乘。
- **以为"加层就更强"**：没有激活，纯线性层会塌缩，深度形同虚设。
- **输出层乱加激活**：回归任务输出层通常**不加激活**（直接输出 z2）；sigmoid 这类一般只在需要概率的输出层用。

## 重点思考题（复习时先自己答，别看要点）

**Q1. 为什么把纯线性层叠起来不会更强？**
> 要点：线性的复合仍是线性，`W2(W1x+b1)+b2 = W'x+b'`，塌缩成单层。

**Q2. 为什么 ReLU 比 sigmoid 缓解梯度消失？（连回 Day 3）**
> 要点：反向传播要连乘各层激活导数；sigmoid 导数≤0.25 连乘趋 0，ReLU 正区间导数=1 不衰减。

**Q3. 单隐藏层 MLP（输入1、隐藏16、输出1）共多少参数？**
> 要点：W1=16, b1=16, W2=16, b2=1，合计 **49**。

**Q4.（迁移）用「模型—损失—优化」描述 MLP 训练，为什么反向传播是关键？**
> 要点：①模型=MLP（W1,b1,W2,b2）；②损失=MSE；③优化=梯度下降，梯度靠反向传播逐层算。参数多且分层，只有反向传播能系统高效地算出所有梯度，梯度下降才有梯度可用。

## 我的心得

① 线性层会塌缩（所以必须有激活）；② ReLU 导数恒为 1（所以能救梯度消失）
