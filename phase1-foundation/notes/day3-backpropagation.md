# Day 3 学习笔记 · 反向传播（Backpropagation）

## 今天搞懂了神经网络"学习"的引擎

一句话：**反向传播 = 自动化的链式法则**，专门用来高效算出"损失对每一个参数的梯度"。
分工要记牢：**反向传播负责"高效算出梯度"，梯度下降负责"拿到梯度后更新参数"**，两者合起来才是完整的训练。

---

## 核心知识点

### 1. 地基：链式法则

依赖链 `w → z → a → L`，想知道 w 动一点 L 变多少，就把链上每段"变化率"连乘：

```
∂L/∂w = ∂L/∂a · ∂a/∂z · ∂z/∂w
```

大白话：像齿轮传动，每级有自己的传动比，总传动比是各级相乘。

### 2. 前向 + 反向两趟

- **前向传播**：从输入算到损失，**把中间量（z、a…）全存下来**（反向要复用）。
- **反向传播**：从损失出发，从后往前逐节点算梯度，一路传回参数。

### 3. 核心思维模式（最该内化）

> **每个节点的梯度 = 上游梯度(upstream) × 本地梯度(local)**

- **本地梯度**：该节点"输出对输入"的导数，只跟自己有关，好算。
- **上游梯度**：从损失一路连乘、传到该节点的梯度。
- 深网络也只需**从后往前扫一遍**，上游梯度被复用 → 这就是它"高效"的来源。

### 4. 一个必备的量

sigmoid 导数：`σ'(z) = a(1−a)`（a 是 sigmoid 输出）。

### 5. 梯度检验（工程习惯）

用数值梯度 `(L(w+ε)−L(w−ε))/(2ε)` 去对比反向传播算出的梯度，两者几乎相等 → 说明推导没错。以后排 bug 常用。

### 6. 从加深一层看出的规律（今天最大收获）

```
∂L/∂w2 = 2(z2−y)·a1                    （靠后的层，链短）
∂L/∂w1 = 2(z2−y)·w2·a1(1−a1)·x         （靠前的层，链长）
```

- 越靠前的层，梯度连乘的项越多；网络每深一层，链就多一段。
- 梯度是"从后往前逐层连乘传回"的。
- **伏笔**：靠前的层连乘很多项，若每项都偏小（sigmoid 导数最大才 0.25），一路乘下来梯度趋近 0 → **梯度消失**；偏大则 **梯度爆炸**。

---

## 易错点（我这次实际踩的坑）

- **合并连乘时漏项**：sigmoid 导数是 `a1(1−a1)` 一个**完整项**，我只写了 `(1−a1)`，把 `a1` 丢了。正确应是 `∂L/∂w1 = 2x·w2·(z2−y)·a1·(1−a1)`。连乘时每一段本地梯度都要完整带上。
- **要能读出"规律"**：层越深、连乘链越长，梯度逐层连乘往回传；越靠前的参数梯度项越多 → 这正是梯度消失/爆炸的根源。别只顾埋头连乘，要退一步看结构。

## 重点思考题（复习时先自己答，别看要点）

**Q1. 反向传播和梯度下降各负责什么？**
> 要点：反向传播用链式法则高效算出所有参数梯度；梯度下降拿这些梯度去更新参数。

**Q2. "上游梯度 × 本地梯度"是什么意思？为什么相乘？**
> 要点：本地梯度=节点输出对输入的导数；上游梯度=从损失连乘传到该节点的梯度；链式法则要求连乘。

**Q3. 反向传播为什么高效？**
> 要点：上游梯度被下游各参数复用，深网络只需从后往前扫一遍，省掉海量重复计算。

**Q4.（迁移）两层网络 z1=w1x+b1, a1=σ(z1), z2=w2·a1+b2, L=(z2−y)²，求 ∂L/∂w1？看出什么规律？**
> 要点：∂L/∂w1 = 2(z2−y)·w2·a1(1−a1)·x（别漏 a1！）。规律：越靠前的层链越长、项越多，梯度逐层连乘传回 → 埋下梯度消失/爆炸。
