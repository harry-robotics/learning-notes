## 一、今天真正想通的一件事

**Transformer 不是凭空发明的，它是被 CNN 和 RNN 的局限逼出来的。**

CNN 靠两个假设吃饭：相关的东西在空间上挨着（局部性）、同一个特征换个位置还是它（平移不变性）。这两个假设对图像太合适了，所以 CNN 打败了 MLP。但假设是有代价的：

- 感受野每层只长 2，图像左上角和右下角要交互，得堆几十层
- 长距离依赖建模不了。"那只在院子里追了半天蝴蝶、浑身沾满泥巴的猫，终于**累**了"——"累"和"猫"隔了 20 多个字

RNN 试图用"一次读一个、边读边记"解决序列问题，但它有两个死穴：固定大小的记忆装不下长序列；而且必须串行，$h_5$ 要等 $h_4$，GPU 几千个核心全在干等。

**所以真正想要的是：任意两个位置直接相连，路径长度恒为 1，且所有位置同时算。** 这就是 self-attention。

对我自己的方向，还有第三条更直接的理由：VLA 模型要让语言指令去"指"图像里的某一块。token「红色的」该关注第 37 个 patch 还是第 142 个，**完全取决于杯子这次摆在哪**——语言 token 和图像 patch 之间根本不存在固定的空间邻近关系。局部性假设在这里彻底失效。**这就是 VLA 的骨架必须是 Transformer 的根本原因。**

## 二、Phase 2 欠的两块

### BatchNorm / LayerNorm

**要解决的问题**：第 5 层的输入是第 4 层的输出，而第 4 层的参数每步都在变，所以第 5 层面对的分布一直在漂移。学习率只能调得很小，深层网络训不动。

**做法**：减均值、除标准差，再乘可学习的 $\gamma$、加可学习的 $\beta$。

$$\hat{x} = \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}, \quad y = \gamma\hat{x}+\beta$$

$\gamma,\beta$ 存在的意义：归一化是我强行规定的，凭什么认为对每层都最优？留这两个可学习参数，模型觉得不合适就能把归一化撤销回去。**所以加归一化最坏也不会变差**——这个论证方式和残差连接一模一样。

**两者的唯一区别是统计方向**（把 batch 想成一张表，行是样本、列是特征）：

- **BatchNorm 竖着算**（跨样本、同通道）→ 我的归一化结果取决于同 batch 里还有谁
- **LayerNorm 横着算**（单样本、跨特征）→ 只看自己，与 batch 里有谁无关

**Transformer 必须用 LayerNorm**：序列长度不定（填充值会污染竖着的统计量），且推理时 batch=1 算不出跨样本统计量。LayerNorm 横着算，这两个问题都不存在。

顺带解开了一个旧疑惑：**`model.eval()` 之前只是我的习惯动作，加了 BatchNorm 之后才有实际后果**——因为 BatchNorm 训练时用当前 batch 统计、推理时改用滑动平均，不切换的话评估结果会依赖测试数据怎么分批。

### 残差连接

**核心不是"加了一项让梯度好传"这么表面，而是改变了什么答案容易学。**

假设某一层最优的行为就是"什么都别改，原样传下去"。让一堆矩阵乘法和激活函数精确学出恒等映射，其实很难。残差换了个问法：不学 $H(x)$，改学 $F(x)$，外面手动加回 $x$：

$$y = F(x) + x$$

表达能力一点没少（$H = F + x$），但**如果最优解是恒等映射，只要学出 $F(x)=0$ 就行——把权重压到 0，这是网络最容易做到的事。** 加法本身不增加任何能力，它只是把"原样传递"从难题变成了送分题。

第二个好处是梯度高速公路：$\partial y/\partial x = \partial F/\partial x + I$，梯度有两条路回传，一条穿过 $F$（衰减），一条从加号直接跳过去（不衰减）。

**注意加的是单位矩阵 $I$ 不是标量 1**——$x,y$ 都是向量，向量对向量求导是矩阵（Jacobian），各项形状必须一致。

## 三、softmax（补课）

一直在用（`CrossEntropyLoss` 内部就含它），但今天才正式学。

**它做的事**：把一组没有约束的实数（logits）变成合法概率分布。**只有两步**：取指数（变正数）、除以总和（和为 1）。

$$s_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

**为什么用 $e^x$**：单调递增（保持排序）；放大差距（让 softmax 更"果断"，attention 里正需要）；导数还是自己（求导干净）。

**名字的含义**：相对 hard-max（argmax）而言。argmax 输出 `[1,0,0]`，最大的通吃，但**不可导，没法 backward**。softmax 输出 `[0.66,0.24,0.10]`，最大的拿最多但别人有份，**处处可导**。

> 「把不可导的硬操作软化以便端到端训练」——这个思路在深度学习里会反复出现，attention 本身就是把"查字典"这个硬操作软化了。

**两个必须记住的性质**：

1. **平移不变性**：所有 logits 加同一个常数，输出不变。PyTorch 内部靠这个减最大值防 exp 溢出。
2. **输入差距越大，输出越接近 one-hot**。`[2,1,0.1]` → `[0.66,0.24,0.10]`；`[20,10,1]` → `[0.9999,...]`。

第 2 条是今天最关键的一条，`/√d_k` 全靠它。

## 四、注意力 = 一次可导的软检索

Query 是我想问什么，Key 是我供人搜索的标签，Value 是我实际提供的内容。

- **硬检索**：找到完全匹配的那一个，返回它的 Value，其余权重全 0 → argmax，不可导
- **软检索**：和每个 Key 算相似度，softmax 成权重，把**所有** Value 加权混合 → 可导

$$\text{Attention}(q,K,V) = \sum_i \alpha_i v_i, \quad \alpha_i = \text{softmax}(q\cdot k_i)$$

**Q、K、V 都从同一个 $X$ 乘三个可学习矩阵来**：

$$Q = XW^Q,\quad K = XW^K,\quad V = XW^V$$

形状上就是三次线性变换：`(5,512) @ (512,64) → (5,64)`，代码里就是三个 `nn.Linear`。

**模型学的不是注意力权重本身，而是"如何提问""如何标注自己""如何提供内容"这三种能力。** 去掉这三个矩阵直接令 $Q=K=V=X$，attention 里就一个可学习参数都没有了，而且相似度矩阵变成对称的（$XX^\top$）——但语义关系本来就不对称。

## 五、核心代码（A 档，要求骨架重建）

```python
def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = Q @ K.transpose(-2, -1) / math.sqrt(d_k)
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn_weights = F.softmax(scores, dim=-1)
    output = attn_weights @ V
    return output, attn_weights
```

**形状主线**：`(5,64)` 进 → 中间产生 `(5,5)` 方阵 → `(5,64)` 出。序列长度不变、特征维度不变，变的是每个位置的内容。

**`scores` 的读法**：第 i 行第 j 列 = 第 i 个 query 对第 j 个 key 的相似度。**行是谁在问，列是问的谁。** 这个对应关系决定了后面 `dim=-1` 的正确性。

### `/√d_k` 的四环因果链（今天最该记住的推理）

```
① 点积方差随维度增长
   q·k 是 d_k 个独立项之和，Var = d_k，标准差 √d_k
   d_k=512 时点积典型值 ±22
        ↓
② 送进 softmax 的数彼此差距极大
        ↓
③ softmax 退化成近似 one-hot（e²² 与 e⁻²² 差 10¹⁹ 倍）
        ↓
④ 输出对输入不再敏感 → 梯度趋近 0 → 训不动
```

第 ④ 环今天用代码实测过：温和输入梯度量级 1e-1，极端输入 1e-5，**差四个数量级**。

### 为什么这么写：三个设计决策

**决策一：函数不自己造 Q/K/V，让调用者传进来。** 因为 Q、K、V 有三种来源组合——self-attention（都来自同一序列）、cross-attention（Q 来自语言、K/V 来自图像）、masked self-attention（GPT 生成）。写死了就没法做 cross-attention，而那恰恰是我方向上最重要的一种。

**决策二：全用负索引。** 因为这个函数要能吃 `(seq,d)`、`(batch,seq,d)`、`(batch,heads,seq,d)` 三种输入。共同点是"序列长度永远在倒数第二、特征维永远在倒数第一"。写成 `Q.size(2)` 今天能跑，明天加 heads 立刻错。

**决策三：把 attn_weights 也返回。** 严格说只需要 output，但权重能画热力图（直接看到模型在读某个位置时在看哪里），也是三个不变量检查的依据。**"把中间结果一并返回以便观察"是研究代码和产品代码的重要区别。**

## 六、三个不变量检查（B 档）

张量代码最阴险的 bug 是**不报错但语义错**——形状合法、程序跑完、loss 也在降，你根本发现不了。抓它的唯一办法是找出必须成立的数学性质然后验证。

| 检查 | 代码 | 在防什么 |
|---|---|---|
| 形状 | `out.shape` 应为 `(2,5,8)` | 转置搞反 |
| 权重每行和为 1 | `attn.sum(dim=-1)` | **`dim` 写错**（唯一能抓住的手段） |
| mask 生效 | 上三角全 0、第 0 行为 `[1,0,0,0,0]` | mask 填错值或用反 |

**这套方法论以后每次都用**：数据对不对（打印一个 batch）→ 模型形状对不对（随机数据走前向）→ loss 算对了吗（构造完美预测看是否接近 0）→ 梯度传到了吗（检查 `.grad` 非零）。每一步都是"找一个必须成立的性质，验证它"。

## 七、易错点（我实际踩的坑）

> 以下是这次真实卡住的地方

**1. 参数量和输出特征图大小混为一谈。**
一开始算 `Conv2d(3,16,k=3)` 的参数量时写成了 `16×32×32=16384`。**那是输出有多少个数，不是有多少个参数。** 正确算法：16 个核 × (3 通道 × 3 × 3) = 432 个权重，加 16 个 bias（每个输出通道一个，不是每个位置一个）= **448**。
前者是每次前向算出来的中间结果，存在 output 里；后者存在模型里被 optimizer 更新。这两个概念以后不能再混。

**2. `dim=-1` 和 `dim=0` 的区别不只是写法。**
scores 是 `(seq_q, seq_k)`，行是"谁在问"。要"每个 query 的注意力分配和为 1"就必须行内归一化，即 `dim=-1`。写成 `dim=0` 变成"每个 key 被关注的总量为 1"，这句话本身没有意义——**而且代码不会报错**。故意跑了一次这个 bug，`attn.sum(dim=-1)` 确实不再是 1。

**3. mask 填 0 的直觉陷阱。**
直觉上"0 = 没有"，但屏蔽发生在 softmax 之前，`exp(0)=1`——**填 0 反而给了它一个不小的权重**。必须填 `-inf`，因为 `exp(-inf)=0`，而且对分母贡献为 0，不会稀释其他位置。

**4.softmax归一化的语义**
对每一个query的注意力分配，加起来必须是1，即看query把100%的注意力分配给了哪些key

**5.为什么说后面的token会影响到前面的token,也就是加上mask的原因**
information leakage:信息泄露 后面的 token 通过 attention 混进了前面的 token 的表示里，而那些后面的 token 恰恰是前面位置要预测的答案。

**6.mask屏蔽的到底是什么位置**
query 只能看自己及以前的 key ,即 key_index > query_index 的格子要屏蔽
