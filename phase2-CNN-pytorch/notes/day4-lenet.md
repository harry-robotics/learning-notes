---

## 一、四个新零件

- **padding（填充）**：图片四周补 0，防止卷积后缩小。3×3 核补 1 圈保尺寸。
- **stride（步幅）**：核每次滑几格。卷积 stride 默认 1；越大输出越小。
- **pooling（池化）**：切块（如 2×2）每块取代表值压缩信息。最大池化 = 每块取最大。**无可学习参数**（区别于卷积）。**默认 stride = 窗口大小**，所以 2×2 池化尺寸减半。
- **channels（通道）**：输入通道=图片层数（灰度1/彩色3，数据定）；输出通道=核个数=特征图数（设计定）；上层输出通道=下层输入通道。

**尺寸公式**：`输出边长 = (输入 − 核 + 2×padding) / stride + 1`（向下取整）。

---

## 二、LeNet 结构

```
输入图 → [卷积→激活→池化] → [卷积→激活→池化] → 展平 → [全连接→激活]×2 → 全连接输出10类
         └────── 特征提取（CNN的活）──────┘         └──── 分类（同MLP）────┘
```

**形状流动（务必能自己追一遍，输入 [b,1,28,28]）**：
- conv1(5×5,pad2,s1) → [b,6,28,28]
- pool(2×2,s2) → [b,6,14,14]
- conv2(5×5,pad0,s1) → [b,16,10,10]
- pool(2×2,s2) → [b,16,5,5]
- 展平 → [b,400] → fc1 → [b,120] → fc2 → [b,84] → fc3 → [b,10]

`fc1 = nn.Linear(16*5*5, 120)` 的 400 = 最后一次池化后 16通道×5×5。

## 四、易错点（含我这次做题踩的坑）

- **【我踩的】形状要看全四维**：`[1,3,32,32]` 过 `Conv2d(3,8,...)` 输出是 `[1,8,32,32]`，通道从 3 变 8，别只盯 H/W 漏了通道。
- **【我踩的】池化默认 stride = 窗口大小（不是1）**：`MaxPool2d(2)` 让尺寸减半。算 LeNet 形状时每个池化都要减半，我上次漏了第二次池化，把 16*5*5 算成了 16*14*14。
- **【我踩的】池化 vs 卷积**：池化**无**可学习参数（固定取最大）；卷积**有**（核权重要训练）。别说反。
- `fc1` 输入维度算错（16*5*5=400）是最常见 CNN bug，不确定就 `print(x.shape)`。
- CNN 训练别 `images.view(...)` 展平，直接吃 4 维图。
- 通道 vs 核个数：输入通道数据定，输出通道=核个数设计定，上层输出=下层输入。

## 五、重点思考题（自测用，遮答案先讲）

**Q. 池化和卷积最大的区别？**
> 池化无可学习参数（固定取最大值）；卷积有可学习参数（核权重要训练）。

**Q. MaxPool2d(2) 的 stride 默认是多少？对尺寸什么影响？**
> 默认 = 窗口大小 2（不是1），所以尺寸减半。这是池化压缩信息的机制。

**Q. LeNet 里 fc1 的 16*5*5=400 怎么来的？**
> 输入 28×28 经 conv1(pad2保尺寸)→pool减半→14，conv2(缩4)→10，pool减半→5，最后 [b,16,5,5] 展平 = 16×5×5=400。每个池化都减半，要跟到最后。

**Q. [1,3,32,32] 过 Conv2d(3,8,k=3,pad=1) 再过 MaxPool2d(2)，形状怎么变？**
> [1,8,32,32] → [1,8,16,16]。通道随核个数变 8，尺寸池化减半。
