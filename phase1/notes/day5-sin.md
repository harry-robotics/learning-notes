## 核心知识点

### 1. 训练循环四步（反复迭代）

**前向（算 ŷ 和损失）→ 反向传播（算梯度）→ 梯度下降（更新参数）→ 回到前向。**

### 2. MLP 反向传播五步梯度（从后往前，"上游 × 本地"）

```
dz2 = (2/n)(ŷ − y)          # 损失对输出
dW2 = a1ᵀ · dz2             # 输出层权重
db2 = sum(dz2, axis=0)      # 输出层偏置
da1 = dz2 · W2ᵀ            # 传回隐藏层激活
dz1 = da1 * (z1 > 0)       # 穿过 ReLU（负区间掐断）
dW1 = Xᵀ · dz1             # 隐藏层权重
db1 = sum(dz1, axis=0)     # 隐藏层偏置
```

### 3. 形状核对法则（排 bug 神器）

**每个参数的梯度形状 = 该参数的形状**（`dW1` 与 `W1` 同形）。形状对不上，一定是转置或求和写错了。

### 4. ReLU 反向

`dz1 = da1 * (z1 > 0)`：前向时 z1>0 的位置梯度原样放行，z1≤0 的位置掐断。

## 我卡住又想通的地方（重点，一定回看）

> 这四点是我这天真正较真、追问后才嚼碎的，比背公式重要得多。

### 想通① 矩阵为什么会进来？——不是新数学，只是"打包"

矩阵乘法**没有引入任何新东西**，它只是把我早就会的一堆 `wx+b`，一次性打包算完的紧凑写法。

让矩阵进来的是**三个"多"**，任何一个都会带来重复运算：
- **一层里有很多神经元**（本例隐藏层 32 个，各有各的权重）；
- **一批有很多样本**（本例 200 个数据点一起过网络）；
- （有时）**每个神经元输入有很多特征**。

**关键澄清**：矩阵**不是"因为特征多"才用的**。今天拟合 sin，输入**只有 1 个特征**，照样用矩阵——因为神经元有 32 个、样本有 200 个。特征多只是三个"多"里的一个，本例里它恰恰是 1。

**打包原理（具体数字）**：把一层里每个神经元的权重摆成矩阵 `W` 的一列。设输入 `x=[2,3]`，
```
W = [1 0 2]
    [0 1 1]
```
`x @ W` 的规则就是"x 和每一列分别做 wx 求和"：
- 神经元1（列 [1,0]）：2·1+3·0 = 2
- 神经元2（列 [0,1]）：2·0+3·1 = 3
- 神经元3（列 [2,1]）：2·2+3·1 = 7

`x @ W = [2,3,7]`，和一个个手算三个神经元**结果完全一样**。矩阵只是把这几次"乘一乘加一加"合并成一步。**本质还是 Day 1 的向量化思想，从一维升到二维。**

### 想通② 转置 `.T` 为什么？——让"要相乘相加"的数对齐

转置的作用是**让该相乘、该求和的那些数，在矩阵里对齐、被一次算完**。

不用每次硬推，用**形状法则倒推**即可：`W2` 是 `(32,1)`，所以 `dW2` 必须是 `(32,1)`；手上有 `a1 (200,32)` 和 `dz2 (200,1)`，要乘出 `(32,1)`，只有 `(32,200)·(200,1)` 这一种搭法 → 所以 a1 要转成 `a1.T`。**形状对上了，转置就对了。**（那个被吃掉的 200 维，就是在跨样本求和。）

### 想通③ 为什么还要"求和"（`np.sum(axis=0)`）？——参数被所有样本共用

根源：**一个参数被 batch 里所有样本共用，每个样本都算出一份梯度，多份梯度必须汇总成一份。**

以偏置 b2 为例：对单个样本，`b2 的梯度 = dz2 × 1 = dz2`（本地梯度是 1，但**梯度本身不是 1，而是上游梯度 dz2**；那个 1 只是"原样传导"）。但 b2 只有一个、被 200 个样本共用，所以要把 200 份 dz2 **加起来** → `sum(dz2, axis=0)`。

权重和偏置并排看就统一了：

| | 本地梯度 | 单样本梯度 | 200 样本共用 → 汇总 |
|---|---|---|---|
| 偏置 b | 1 | `dz2` | 求和 `Σ dz2` |
| 权重 W | 输入 a1 | `dz2 × a1` | 求和 `Σ(dz2 × a1)` |

- **"求和"是两者共有的**——所有参数都被全部样本共用，都要跨样本汇总。偏置不特殊。
- **"乘输入"是权重独有的**——权重的本地梯度是它连的那个输入；偏置的本地梯度是 1，没输入可乘。
- 权重那份"乘输入 + 求和"被矩阵乘法 `a1.T @ dz2` 一步打包；偏置不用乘输入，求和就露在外面成了 `np.sum`。

### 想通④ "拟合 sin"到底是什么？和识别手写数字什么关系？

**神经网络本质就是一台"拟合函数的机器"。识别手写数字和拟合 sin，底层是同一件事**——给一堆"输入→输出"的例子，让网络学出那个把输入变成输出的函数：
- 手写数字：学 `f(图片784像素) → 数字0~9`；
- 拟合 sin：学 `f(x) → sin(x)`。

机制完全相同（前向/损失/反向/梯度下降），只差**复杂度**。用 sin 教学，是因为它是神经网络的"Hello World"：① 一进一出，能把目标和网络输出画在一张图上**亲眼看着**它拟合；② 无限完美标签，不用数据集；③ 剥掉杂事，只检验"我手写的反向传播对不对"——曲线拟合上了就证明梯度全推对了。

（更深一层：universal approximation theorem——够宽的单隐藏层 MLP 能逼近任意连续函数；拟合 sin 就是在见证这台"万能函数逼近器"。）

**连到我的目标**：自动驾驶 / 具身智能里，网络学的也是函数（如"图像 → 方向盘转角"、"状态 → 动作"），还是拟合函数，只是输入输出复杂得多。今天这个拟合 sin 的小玩具，就是将来那些真家伙的等比例缩小版，机制一模一样。

## 易错点（我这天实际卡过的坑）

- **以为矩阵是"因为特征多"才引入**：其实"神经元多 / 样本多 / 特征多"任一个都会引入矩阵；本例特征只有 1 个，是 32 个神经元和 200 个样本把矩阵拉进来的。
- **把"本地梯度 = 1"误当成"梯度就是常数 1"**：那个 1 只是"原样传导"，真正传下来、要被汇总的是上游梯度 `dz2`。
- **以为偏置求和是因为它特殊**：其实**所有参数（权重也一样）都要跨样本求和**，因为参数被所有样本共用；只是权重额外要"乘输入"。

## 重点思考题（复习时先自己答，别看要点）

**Q1. 为什么求 db2 要对样本维（axis=0）求和？**
> 要点：b2 被 batch 里所有样本共用，每个样本产生一份梯度，多份要汇总成一份。所有参数都如此，非偏置独有。

**Q2. 去掉隐藏层 ReLU（变纯线性两层），还能拟合 sin 吗？**
> 要点：不能。纯线性会塌缩成单层线性（只能画直线），拟合不了弯曲的 sin。ReLU 的非线性是拟合弯曲函数的关键。

**Q3.（综合）口述 MLP 完整训练流程；加深到 3、4 层，哪些改、哪些不改？**
> 要点：模型(前向线性+激活逐层)→损失(MSE)→优化(反向传播逐层上游×本地算梯度 + 梯度下降更新)。加深只需多写几层前向/反向、参数更多；整套机制、"模型-损失-优化"框架、上游×本地、形状核对、跨样本求和——完全不用改。
