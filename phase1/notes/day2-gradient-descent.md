# Day 2 学习笔记 · 损失函数 + 梯度下降（Gradient Descent）

## 今天补齐了"训练"的最后一块拼图：优化

Day 1 我有了**模型**（`ŷ = w·x + b`）和**损失**（MSE），还看到损失随参数是一条"碗状"曲线。今天学的**梯度下降**，就是让机器**自动走到碗底**的方法——「模型 → 损失 → 优化」框架里的**优化**这一步，至此三件套齐了。梯度下降是几乎所有深度学习模型（从线性回归到 GPT）训练的通用引擎。

---

## 核心知识点

### 1. 梯度下降的直觉（下山比喻）

蒙眼站在山坡上想走到谷底：感受脚下**最陡的上坡方向**，然后朝**相反方向**迈一步，重复。搬到我的问题上：
- "山的高度" = 损失 `L`；"我的位置" = 参数 `w, b`。
- "脚下最陡上坡方向" = **梯度(gradient)** = 损失对参数的导数 `∂L/∂w`。
- 朝**负梯度**方向走，损失一定下降。（梯度指向上坡，所以我往它反方向走才是下坡。）

### 2. 更新公式（今天的核心，必背）

```
w := w − lr · ∂L/∂w
b := b − lr · ∂L/∂b
```

- `lr`（learning rate 学习率）：步子大小，我自己设的小正数。
- 减号：朝负梯度（下坡）走。
- 反复执行很多轮，参数就滑到谷底——这个反复过程就是"训练"。

### 3. 学习率 lr

太大 → 步子迈太狠，在谷底两边横跳甚至越跳越远（**发散/爆炸**）；太小 → 走得太慢。选合适的 lr 是最基本的调参功夫。

### 4. MSE 的梯度（公式 ↔ 代码一一对应）

```
∂L/∂w = (2/n) Σ (ŷ − y)·x        →  grad_w = (2/n) * np.sum(error * X)
∂L/∂b = (2/n) Σ (ŷ − y)          →  grad_b = (2/n) * np.sum(error)
```

- 求 `∂L/∂w` 时每个误差**乘上它自己的 x**：因为 w 乘在 x 上，x 越大的样本，w 的变化对它影响越大，梯度贡献也越大。
- 求 `∂L/∂b` 不乘 x：b 是直接加上去的，对每个样本影响力一样。

### 5. 训练循环骨架（记住这个套路，以后都一样）

**前向算预测 → 算损失 → 算梯度 → 更新参数 → 重复。**

---

## 易错点（我这次实际踩的坑）

- **epoch 的定义别说笼统。** 不是模糊的"一个训练轮数"，准确说是**把全部训练数据完整过一遍**。要很多个 epoch，是因为每轮只把参数往谷底挪一小步，得反复很多轮才逼近最优。
- **「局部最小值」≠「相近的数据」（这题我概念搞混了，重点记）。** 损失曲面坑坑洼洼说的是**参数空间里的地形**，跟数据点无关。梯度下降是"只看脚下坡度"的**局部方法**，会滑进离起点最近的那个坑（**局部最小值 local minimum**）就停，不一定是**全局最小值 global minimum**；而且停在哪很依赖**初始参数位置**。
- **迁移题要能完整复述通用流程。** 光说"可导→梯度→优化"不够，得能把整个循环（预测→损失→梯度→更新→重复）独立讲出来。

## 重点思考题（复习时先自己答，别看要点）

**Q1. 梯度下降为什么是"减去"梯度，而不是加上？**
> 要点：梯度指向上坡（损失增大）方向，要减小损失就得朝反方向走 → 减去梯度 = 沿负梯度 = 下坡。

**Q2. 一个 epoch 到底指什么？为什么要很多个 epoch？**
> 要点：一个 epoch = 全部训练数据完整过一遍；每轮只挪一小步，多轮才能逼近谷底、损失降够低。

**Q3. 损失曲面有多个局部最低点时，梯度下降会遇到什么麻烦？**
> 要点：只看脚下坡度的局部方法，会卡进最近的局部最小值（未必全局最优），且结果依赖初始位置。

**Q4.（迁移）把梯度下降写成一个不依赖具体模型的通用流程，并说明为什么对任意可导模型都成立？对应框架哪一步？**
> 要点：①算预测 →②算损失 →③算梯度 →④参数 := 参数 − lr×梯度 →⑤重复。只要损失对参数可导就能算梯度、套同一更新公式，与模型形式无关。对应"优化"。
